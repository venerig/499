PDU: dati (L7-5) → segmento/datagramma (L4) → pacchetto (L3, router, IP) → frame (L2, switch, MAC) → bit (L1, hub). TTL: −1 a ogni router, a 0 il pacchetto è scartato.

Trappola quiz

IMAP/POP3 ricevono, SMTP invia. Hardening SSH = niente root + chiavi; cambiare porta non è sicurezza. FTP e SFTP non hanno limiti di 4/16 GB (errore del video).
