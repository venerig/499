Estensioni, scorciatoie, malware, concetti base

Stampabile — tienila a portata per il ripasso rapido prima dei quiz a tempo.

Estensioni: .exe eseguibile · .jpg con perdita · .png senza perdita, trasparenza · .gif 256 colori, animata · .psd Photoshop · .pps/.ppsx presentazione diretta · .pst dati Outlook · .csv valori separati · .zip/.rar/.7z archivi.

Scorciatoie: Ctrl+C/X/V copia/taglia/incolla · Ctrl+Z/Y annulla/ripeti · Ctrl+A tutto · Alt+Tab finestre · Win+L blocca · Win+E Esplora file · Win+D desktop · Ctrl+Alt+Canc schermata sicurezza · Ctrl+Shift+Esc Gestione attività · F2 rinomina.

Malware: spyware spia · keylogger registra tasti · adware pubblicità · rootkit si nasconde · spoofing falsa identità · spam invio di massa.

Concetti: dato → informazione (dato in contesto) → conoscenza · sistema informatico ⊂ sistema informativo · autenticazione = chi sei, autorizzazione = cosa puoi fare · 1 KB = 1024 byte nei quiz (SI kB = 1000, IEC KiB = 1024) · CCN = destinatari nascosti.
