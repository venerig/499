Il tranello più comune

La case-sensitivity è il contrasto più chiesto: su Linux Report.docx e report.docx sono due file distinti nella stessa cartella; su Windows, no (collisione, stesso file).

Permessi

Linux: modello rwx (read/write/execute) per tre categorie — owner, group, other — espresso anche in notazione numerica (es. 755 = owner rwx, group r-x, other r-x). Windows: ACL (Access Control List) più granulare, con permessi assegnabili per singolo utente o gruppo su ogni oggetto, non solo tre categorie fisse.

Processi e shell

Analogia per fissarla

Pensa a bash come a una pipeline CI che passa stringhe grezze tra step (devi fare parsing tu); PowerShell passa oggetti tipizzati tra step (puoi accedere direttamente alle proprietà) — stesso concetto delle pipeline Jenkins che già conosci, applicato alla shell del sistema operativo.

Server vs client

Non è una differenza di kernel, ma di ruolo e configurazione: Windows Server offre ruoli enterprise (Active Directory, DNS, DHCP server) assenti nelle edizioni client; le distribuzioni Linux "server" (es. Ubuntu Server, Red Hat Enterprise Linux) tipicamente non installano un'interfaccia grafica di default (headless), a differenza delle edizioni desktop.

Verifica — retrieval practice

L'ordine delle opzioni cambia a ogni caricamento — rispondi dal ragionamento, non dalla posizione.

1. Il file system NTFS di Windows è, di default:

NTFS è case-insensitive di default: "File.txt" e "file.txt" sono visti come lo stesso nome. I file system Linux più comuni (ext4, XFS) sono invece case-sensitive.

2. Cosa rappresenta il permesso Linux espresso come "755"?

La notazione numerica rwx codifica i permessi per owner/group/other: 7 = rwx, 5 = r-x. "755" significa owner con tutti i permessi, group e other solo lettura ed esecuzione.

3. Qual è il processo con PID 1 nei moderni sistemi Linux che usano systemd?

systemd è il processo di init, avviato con PID 1 dal kernel, e gestisce l'avvio e il ciclo di vita di tutti i servizi successivi.

4. Qual è la differenza principale tra il modello di pipeline di bash e quello di PowerShell?

Bash passa stringhe di testo tra comandi concatenati; PowerShell passa oggetti .NET con proprietà accessibili direttamente, senza bisogno di fare parsing testuale.

5. Cosa caratterizza tipicamente un'installazione server di una distribuzione Linux rispetto a un'edizione desktop?

Le distribuzioni server (Ubuntu Server, RHEL...) tipicamente non installano una GUI di default — stesso kernel e stessa base del sistema, configurazione e ruoli diversi.
