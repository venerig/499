Architettura di von Neumann

Lo schema di riferimento di (quasi) ogni computer moderno: CPU (unità di elaborazione centrale, a sua volta ALU + registri + unità di controllo), memoria (dati e istruzioni nello stesso spazio di memorizzazione), bus (canali che collegano i componenti: bus dati, bus indirizzi, bus di controllo) e I/O (periferiche di input/output). Il ciclo base della CPU è fetch → decode → execute: preleva l'istruzione, la decodifica, la esegue.

Trappola quiz

"ALU" (Arithmetic Logic Unit) esegue operazioni aritmetiche/logiche; l'unità di controllo coordina il ciclo fetch-decode-execute e pilota gli altri componenti — nei quiz vengono spesso scambiate le due funzioni.

Regola generale della gerarchia: più sei vicino alla CPU, più sei veloce, più piccolo e più costoso per byte. La RAM perde il contenuto allo spegnimento (volatile); disco e ROM lo conservano (non volatile) — è il contrasto più chiesto nei quiz su questo argomento.

Logica booleana

Le porte logiche sono i mattoni elementari con cui è costruito l'hardware digitale (incluse le ALU). Le tabelle di verità delle quattro porte base:

PortaOutput = 1 quando...
ANDEntrambi gli input sono 1
ORAlmeno un input è 1
NOTL'unico input è 0 (inverte)
XORGli input sono diversi tra loro (uno 0 e uno 1)

Il tranello più comune

XOR non è "OR esclusivo nel senso di OR più permissivo": è vero solo quando gli input differiscono. Con input 1,1 l'OR normale dà 1, ma lo XOR dà 0 — è lo scambio più frequente nei quiz su logica booleana.

Rappresentazione binaria

Un bit è l'unità minima (0 o 1); un byte sono 8 bit. I numeri negativi negli interi si rappresentano in complemento a 2, non con un semplice bit di segno — è la convenzione usata da (quasi) tutte le CPU moderne.

Verifica — retrieval practice

L'ordine delle opzioni cambia a ogni caricamento — rispondi dal ragionamento, non dalla posizione.

1. Qual è il ciclo base di esecuzione di una CPU?

Fetch (preleva l'istruzione) → decode (la decodifica) → execute (la esegue) è il ciclo base di ogni CPU von Neumann.

2. Quale affermazione sulla RAM è corretta?

La RAM è volatile: senza alimentazione il contenuto si perde. Disco e ROM sono non volatili.

3. In logica booleana, quando una porta XOR restituisce 1?

XOR è vero solo quando i due input differiscono (uno 0 e uno 1) — con input uguali (1,1 o 0,0) il risultato è sempre 0.

4. Quanti bit compongono un byte?

Un byte è definito come 8 bit — base di ogni unità di misura successiva (KB, MB, GB...).

5. Quale componente della CPU coordina il ciclo fetch-decode-execute e pilota gli altri componenti?

L'unità di controllo coordina il ciclo di esecuzione; l'ALU esegue le operazioni aritmetiche/logiche effettive, ma non pilota il ciclo.
