Il tranello più comune: "C#" non deriva da "C++"

Il nome suggerisce una progressione C → C++ → C#, ma C# è un linguaggio a sé, creato da Microsoft, sintatticamente vicino a Java/C++ ma eseguito su una piattaforma diversa (.NET CLR) e senza l'ereditarietà diretta che il nome implica. Un quiz che chiede "C# è un'evoluzione diretta del C++?" si aspetta falso.

Statico vs dinamico, non "compilato vs interpretato"

Sono due assi diversi che si confondono facilmente: la tipizzazione (quando si controllano i tipi: a compile-time = statica, a runtime = dinamica) è indipendente dalla modalità di esecuzione (compilato/interpretato/gestito, vista in lezione 16). Java è staticamente tipizzato ma gestito via bytecode+JVM; Python è dinamicamente tipizzato e interpretato. Non sono la stessa cosa, anche se spesso vanno a braccetto nei linguaggi più comuni.

Richiamo dalla lezione 16: Java e Python sono tecnicamente "ibridi" (bytecode + macchina virtuale), ma nei quiz a due sole opzioni (compilato/interpretato) Java viene trattato come "compilato" (per la JVM) e Python come "interpretato" — è la semplificazione da manuale, non la descrizione tecnicamente più precisa.

Verifica — retrieval practice

L'ordine delle opzioni cambia a ogni caricamento — rispondi dal ragionamento, non dalla posizione.

1. Quale di questi linguaggi ha tipizzazione dinamica?

Python controlla i tipi a runtime (tipizzazione dinamica). Java, C# e C sono tipizzati staticamente: i tipi si controllano a compile-time.

2. Su quale piattaforma/ambiente di esecuzione gira tipicamente il codice C#?

C# viene compilato in IL (Intermediate Language) ed eseguito dal CLR di .NET — stesso schema "gestito" della JVM per Java, ma piattaforma diversa.

3. "C# è un'evoluzione diretta di C++, come C++ lo è di C." Questa affermazione è:

Il nome è ingannevole: C# è sintatticamente vicino a Java/C++ ma è un linguaggio indipendente creato da Microsoft per la piattaforma .NET, non una terza iterazione evolutiva di C.

4. Quale linguaggio, tra questi, è tipicamente usato lato client in una pagina web eseguita nel browser?

JavaScript è il linguaggio nativo di esecuzione lato client nei browser (ed è anche usabile lato server con Node.js). Gli altri tre non sono linguaggi nativi del browser.

5. Quale coppia di linguaggi condivide lo stesso schema di esecuzione "gestito" (compilazione intermedia + macchina virtuale)?

Java (bytecode + JVM) e C# (IL + CLR) condividono lo stesso schema concettuale di esecuzione gestita, anche su piattaforme diverse. C/C++ sono compilati nativi; Python/JavaScript sono interpretati/JIT senza una compilazione intermedia "gestita" equivalente nel senso da manuale.
